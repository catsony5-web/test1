# 가계부 전용 에이전트

가계부의 기존 계산과 저장 경로를 사용하는 웹 기능입니다. 휴대폰과 데스크톱에서 같은 화면을 사용합니다. 실제 개인정보는 사용자의 가계부에서만 읽으며 소스·테스트에 넣지 않습니다.

## 제공 상태

| 기능 | 상태 |
| --- | --- |
| 월 지표·월 비교·가족 정산·거래 검색 | AI 연결 없이 브라우저에서 사용 |
| 기존 거래 수정 미리보기·사용자 적용 | 브라우저에서 사용 |
| 사용자 API 키를 이용한 대화·도구 실행 | 별도 게이트웨이 실행 및 사용자의 과금 동의 후 연결 |
| 개인 PC의 ChatGPT 구독 로그인 | 로컬 서버에서 공식 OAuth 로그인, 계정 선택과 구독 권한 확인 후 사용 |
| GitHub Pages 화면에서 같은 PC의 구독 사용 | PC 연결 창을 열고 계정·모델 선택 및 해당 사이트 연결 허용 후 사용 |
| 원격 웹서비스의 ChatGPT 구독 로그인 | 별도 접근 승인과 승인된 인증 계약 연결 필요 |

개인 PC에서는 **Continue with ChatGPT**로 연결합니다. 계정의 구독 사용 권한이 확인되어야 AI 요청을 보낼 수 있습니다. 원격 origin으로 설정한 서버에서는 로컬 구독 로그인을 제공하지 않습니다. 구독 제한·오류 시 API 과금으로 자동 전환하지 않습니다.

### 공개 사이트에서 이 PC 연결

1. 최신 프로젝트 폴더에서 `npm run agent`를 실행합니다. 이 연결 방식은 기본 주소 `http://127.0.0.1:4185/`를 사용합니다.
2. 같은 PC의 공개 가계부 사이트에서 **가계부 에이전트 → 이 PC의 구독 연결**을 누릅니다.
3. 열린 PC 연결 창에서 요청한 사이트 주소를 확인하고 계정과 모델을 선택합니다. 계정이 없거나 권한이 만료되었으면 이 창에서 ChatGPT 로그인을 진행합니다.
4. **이 사이트에 연결 허용**을 누른 뒤 원래 사이트의 대화창을 사용합니다. 조회 대상은 공개 사이트에 저장된 가계부입니다. PC의 별도 가계부가 복사되거나 합쳐지지 않습니다.
5. 사용 중에는 연결 창과 PC 서버를 유지합니다. **이 사이트의 PC 연결 해제**는 사이트 연결만 해제하며, ChatGPT 계정 자체를 로그아웃하지 않습니다.

사이트와 PC 연결 창은 정확한 origin·창 참조·일회 연결 식별자를 확인하고 전용 메시지 채널로 통신합니다. 브라우저의 사이트 신뢰 경계는 URL 경로가 아닌 origin 전체입니다. 연결 창의 직접 허용 전에는 저장된 계정 정보가 사이트에 전달되지 않습니다. 연결 후에도 선택한 계정의 표시 정보와 모델·대화 응답만 전달하며, 전체 계정 목록·API 키·인증 토큰·로컬 가계부는 전달하지 않습니다. 사이트에서 로그인·로그아웃이나 임의 로컬 API를 실행하는 기능은 제공하지 않습니다.

PC 연결 페이지와 스크립트는 로컬 서버에서만 제공하며 GitHub Pages 산출물과 서비스워커 캐시에 넣지 않습니다. 로컬 API의 same-origin 검사, 루프백 바인딩, CORS 제한을 유지합니다. 서버가 꺼져 있거나 팝업이 차단되면 연결 안내를 표시합니다. 휴대폰의 `127.0.0.1`은 그 휴대폰이므로 이 기능은 같은 PC의 브라우저 사용을 위한 것입니다.

## 사용 순서

1. 화면 상단의 **가계부 에이전트**를 엽니다.
2. **바로 확인**에서 대상월·비교월·검색어를 입력한 뒤 조회합니다. 결과는 현재 열린 가계부에서 계산합니다.
3. 검색한 거래의 **이 거래 수정 검토**에서 새 값을 입력합니다. **변경 전후 미리보기**까지는 저장하지 않습니다.
4. 변경 내용을 확인한 뒤 **확인한 변경 적용**을 누릅니다. 이전에 조회한 기록이 바뀌었으면 최신 기록을 다시 조회해야 합니다.
5. **Continue with ChatGPT**를 눌러 열린 OpenAI 화면에서 사용할 계정으로 로그인하고 구독 사용 권한을 확인합니다. 다른 계정을 쓰려면 **다른 ChatGPT 계정 추가**를 선택합니다. 비밀번호는 가계부에 입력하지 않습니다.
6. 연결된 계정과 사용 모델을 확인한 뒤 자연어로 검색·비교·수정을 요청합니다. 모델의 수정 제안도 같은 미리보기와 적용 과정을 거칩니다.
7. 저장된 계정을 선택하면 해당 계정의 모델 목록을 새로 읽습니다. 계정 전환 시 기존 대화와 미적용 제안을 지웁니다. 가계부 자체는 자동으로 바뀌지 않습니다.
8. **ChatGPT 로그아웃**은 선택한 계정의 갱신 세션을 해지하고 이 PC의 인증 토큰을 지웁니다. 나중에 재로그인할 수 있도록 계정 등록 정보는 유지합니다. 원격 해지가 확인되지 않으면 안내에 따라 ChatGPT 사용량 설정에서 연결을 확인합니다.
9. 별도 API 과금을 원하는 경우에만 **내 API 키로 유료 연결**에서 동의 후 연결합니다. **새 대화**는 대화와 미적용 제안을 지우며 가계부 기록은 유지합니다.

AI 로그인은 가계부 데이터 동기화를 대신하지 않습니다. 현재 열린 로컬 가계부 또는 기존 암호화 Drive 가계부가 조회 대상입니다. 여러 사용자는 자신의 기기·브라우저 프로필 또는 자신의 가계부를 사용해야 합니다. 승인된 웹 로그인 도입 시 계정과 가계부 소유권 연결도 검증해야 합니다.

## 실행과 웹 배포 경계

```sh
npm run agent
```

기본 주소는 `http://127.0.0.1:4185/`입니다. 같은 PC에서 서버를 실행하고 브라우저를 열어 사용합니다. 공개 도메인이나 회사 등록이 필요하지 않습니다. OAuth 콜백도 실제 `127.0.0.1`에서만 받습니다.

브라우저 연결 세션은 미사용 30분 또는 연결 후 8시간에 만료됩니다. 저장된 ChatGPT 계정은 다시 선택할 수 있으며, 인증 권한이 만료되었으면 재로그인합니다. 선택적 API 키는 서버 메모리에만 유지되므로 서버 재시작 후 다시 입력해야 합니다. 키를 환경 파일에 넣을 필요는 없습니다.

환경 설정:

| 변수 | 용도 |
| --- | --- |
| `LEDGER_AGENT_PORT` | 루프백 리스닝 포트, 기본 4185 |
| `LEDGER_AGENT_ORIGIN` | 운영 HTTPS origin. 개발 시 HTTP 루프백만 허용 |
| `LEDGER_AGENT_BASE_PATH` | 사이트 하위 경로, 기본 `/`; 예시 `/ledger/` |
| `LEDGER_AGENT_DIST` | `1`이면 검증된 `dist/`의 공개 자산 사용 |
| `LEDGER_AGENT_ENABLE_API` | `0`이면 선택적 API 연결도 비활성화 |
| `LEDGER_AGENT_ENABLE_SUBSCRIPTION` | `0`이면 로컬 ChatGPT 로그인도 비활성화 |

운영에서는 HTTPS 역방향 프록시 뒤에 게이트웨이를 둡니다. 공개 origin의 Host를 유지하고 해당 base path의 `agent-api/`와 공개 웹 자산을 같은 origin에 제공합니다. 임의 외부 서버 URL 입력이나 광범위한 CORS 허용은 제공하지 않습니다. CSP는 기존 same-origin 연결을 사용합니다.

GitHub Pages 단독 배포는 Node 게이트웨이를 실행하지 못합니다. Pages에서는 기본 조회·수정 미리보기를 브라우저에서 사용하고, 개인용 AI 대화는 위의 PC 연결 창을 통해 실행합니다. `npm run build`는 허용 목록의 공개 자산만 복사하며 서버 코드·테스트·자격증명은 포함하지 않습니다.

현재 게이트웨이는 단일 프로세스 브라우저 세션을 사용합니다. 여러 인스턴스 운영에는 별도 세션 설계가 필요합니다. 프록시 접근 로그에 요청 본문·Cookie·Authorization을 기록하지 않아야 합니다. 사용자가 입력한 API 키는 게이트웨이를 거쳐 OpenAI로 전달되므로 운영 주체의 서버를 신뢰할 수 있어야 합니다.

연결 시도 제한은 소켓 주소를 기준으로 합니다. 역방향 프록시 뒤에서는 사용자들이 같은 제한을 공유할 수 있으므로 공개 운영 전에 프록시의 신뢰 범위와 사용자별 호출 제한을 설정해야 합니다.

## 데이터와 승인 경계

- 모델에는 조회 결과의 필요한 필드만 전달합니다. 카드번호·승인번호·파일명·원본 recordKey 대신 대화 내 불투명 거래 참조와 카드 별칭을 사용합니다. 거래명·메모는 질문에 필요할 수 있으므로 응답에 포함됩니다.
- 가계부 계산은 기존 `reportingExpenseRows`, `consumptionAmount`, `buildMonthlyFlowRow`, `buildFamilySupportModel`을 사용합니다. 정산금·가족 부담·할부·대출원금 및 예정지출의 처리 기준을 유지합니다.
- 취소·환불 원결제 연결이 확정되지 않은 기존 데이터는 경고로 표시합니다. 모델이 추정한 취소 상계로 앱 숫자를 바꾸지 않습니다.
- `propose_changes`는 미리보기만 만들며 모델에 `apply_changes` 도구를 제공하지 않습니다. 실제 적용은 사용자의 버튼 클릭으로만 시작됩니다.
- 날짜·원 단위 금액·분류·정산금·거래 참조를 검증합니다. 대출·할부·고정지출에 연결된 금액·날짜·정산 변경은 기존 전용 화면으로 안내합니다. 거래 생성·삭제·계좌 이체는 이 도구의 범위가 아닙니다.
- 저장 직전에 메모리 상태, 저장소/보관함 세대, 저장된 관련 데이터를 확인합니다. `safeSaveMany`의 `expectedJson` 비교를 기존 저장 트랜잭션 안에서 수행하여 오래된 미리보기의 덮어쓰기를 막습니다. 성공한 뒤에만 화면 상태를 교체합니다.
- 인증키와 대화는 가계부 백업에 포함되지 않습니다. 적용한 거래 변경은 기존 저장·동기화·백업 경로를 사용합니다.
- ChatGPT 등록 정보와 토큰은 가계부 저장소와 별개인 이 PC의 `%LOCALAPPDATA%\PersonalBudget\ChatGPT\profiles.dpapi`에 보관합니다. Windows에서는 DPAPI로 보호하며 토큰을 브라우저 저장소·소스·로그에 기록하지 않습니다. 호스트 식별자는 계정을 바꿔도 유지하고, 계정별 등록·토큰은 분리합니다.
- OAuth의 state·PKCE·nonce와 ID 토큰 서명·발급자·대상 클라이언트·만료·계정 동일성을 검증합니다. 구독 요청은 공식 Responses API에 `store:false`, `stream:true`로 보내며 완료 이벤트가 있어야 성공으로 처리합니다.
- 구독 경로는 [공식 preview 제약](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)에 맞춰 함수 도구를 `ledger` namespace로 묶고 `max_output_tokens` 등 미지원 필드를 제외합니다. 일반 API 연결의 요청 형식과는 구분합니다.
- 서버는 고정된 OpenAI API 주소만 호출하며 사용자별 세션을 분리합니다. HttpOnly/SameSite 쿠키, 운영 Secure 쿠키, origin/Host 검사, 요청 크기·횟수·시간 제한을 사용합니다. 저장이나 임의 명령 실행 권한은 서버에 없습니다.
- API 모델 목록은 접근 가능한 모델의 후보입니다. 목록 조회만으로 해당 모델의 Responses 도구 호출 지원까지 보장하지 않으며 오류는 사용자에게 표시합니다. 실제 키를 사용한 유료 호출은 자동 테스트에서 하지 않습니다.

## 휴대폰 개인 접속의 후속 구성

현재 단계는 PC 로컬 사용입니다. 휴대폰의 `127.0.0.1`은 PC를 가리키지 않습니다. 본인 휴대폰 접속은 PC에서 OAuth를 완료하고 토큰·갱신을 PC에 둔 상태에서, 소유자만 허용한 사설 VPN과 HTTPS 연결을 마련하는 방향으로 검토합니다. 공개 포트나 공개 터널을 열지 않습니다. 프록시 뒤의 요청을 무조건 소유자로 신뢰하지 않고 기기 또는 소유자 인증을 추가해야 합니다.

휴대폰의 브라우저 저장소는 PC와 별개입니다. 같은 기록을 보려면 기존 암호화 동기화 또는 사용자 확인을 거친 백업 복원이 필요합니다. 이번 PC 로그인 구현은 휴대폰 네트워크 연결이나 동기화를 자동 설정하지 않습니다. 공식 [자체 호스팅 안내](https://developers.openai.com/siwc/token-sharing-open-source/self-hosted-vms)도 OAuth의 로컬 완료와 인증 정보 보호를 구분합니다.

## 원격 웹서비스로 확장할 때

[공식 가이드](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt)는 로컬 개인 프로젝트의 구독 사용을 안내하며, 사용자들에게 제공하는 유료·원격 호스팅 앱은 접근 신청 대상으로 구분합니다. 같은 사용자의 [개인 자체 호스팅 VM](https://developers.openai.com/siwc/token-sharing-open-source/self-hosted-vms)도 별도로 안내되므로 원격이라는 이유만으로 모두 상용 신청 대상으로 보지 않습니다. 현재 PC 연결은 본인 PC가 인증·AI 요청을 처리하는 개인용 구성입니다. 사용자 대상 원격 웹서비스로 확장할 때는 [신청 안내](https://developers.openai.com/siwc/request-client-id)를 확인해야 합니다. 다음 내용을 신청 초안으로 사용할 수 있습니다. 아직 제출하지 않았습니다.

- 제품: 소비 분석 가계부 웹앱. 데스크톱·모바일 브라우저에서 이용하는 개인 가계부 전용 에이전트.
- 사용 사례: 사용자의 거래 검색, 기간별 소비 비교, 정산·예산 지표 조회, 승인 후 기록 수정.
