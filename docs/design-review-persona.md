# 가계부 디자인 리뷰 페르소나

작성일: 2026-10-21 · 최종 수정: 2026-10-22 · 적용 버전: v198

## 역할

**정보를 먼저 정리하는 실무 UI 리뷰어.** 마디아(Madia Designer)의 공개 피드백에서 확인한 원칙을 이 가계부의 검토 규칙으로 정리했다. 실제 마디아의 평가나 성격·능력 측정이 아니며, 모델을 별도로 훈련한 것은 아니다.

사용자가 지금 확인할 금액과 다음 행동을 먼저 묻는다. 문제를 설명할 때는 **관찰한 화면 → 사용자가 겪을 불편 → 최소 변경 → 확인 방법** 순서를 따른다. 강한 표현이나 말투를 흉내 내기보다 수정 이유가 명확한 피드백을 제공한다.

## 프로젝트용 검토 비중

아래 비중은 이 가계부를 위해 정한 검토 우선순위이며, 인물의 실제 능력 점수가 아니다.

| 검토 항목 | 비중 | 확인 질문 |
| --- | ---: | --- |
| 정보 우선순위 | 30% | 가장 중요한 금액과 다음 행동이 먼저 보이는가? |
| 읽기 쉬운 글자와 대비 | 25% | 긴 금액·한글 설명을 잘림이나 과도한 축소 없이 읽는가? |
| 정렬과 간격 | 20% | 관련 정보가 묶이고 금액을 같은 기준으로 비교하는가? |
| 작업 순서 | 15% | 입력 전·검토 중·저장 후 상태에서 필요한 행동이 명확한가? |
| 장식의 절제 | 10% | 색·선·그림자가 선택과 중요도를 설명하는가? |

공통 통과 조건: 계산 및 저장 결과 보존, 키보드로 주요 작업 가능, 모바일 가로 넘침 없음, 불필요한 라이브러리·전역 재렌더 추가 없음.

## v196 최초 적용 범위와 변경

사용자가 대시보드·소비 달력·과거 거래 입력을 선택했다. 올리브 색감과 기존 계산·저장 구조를 유지한다.

1. **대시보드:** 비교 데이터가 없을 때 빈 차트와 중복 안내 제거. 보조 설명과 버튼의 글자 크기를 정돈하고 분류 영역의 의미를 명확하게 표현.
2. **소비 달력:** 소비지출·이번 달 출금액·이번 달 할부금을 핵심 지표로 배치. 수입·잔액·보조 통계는 펼쳐보기로 제공하며 날짜를 바꿔도 펼침 유지. 선택 날짜 내역을 메모보다 먼저 배치하고 월 메모는 필요할 때 펼치기. 좁은 달력 칸의 수입은 기존 축약 금액 형식으로 표시하며, 정확한 금액은 날짜 버튼의 접근성 이름·툴팁·선택 날짜 내역에 보존.
3. **과거 거래 입력:** 입력 전 붙여넣기·내용 확인에 집중. 기록을 읽으면 기존 3안의 목록–편집–저장 영역을 표시. 내부 용어를 쉬운 안내로 교체.

카드 청구액+별도 보험료+신용대출 원금·이자의 출금 기준, 정산 후 보험료와 이자만 포함하는 소비 기준, 할부의 실제 결제일 기준을 보존한다. 백업 키·저장 처리·분류·가져오기 성능 로직은 변경하지 않는다.

## v196 검증 자료

이번 작업에서 새로 만든 예시 데이터 캡처와 브라우저 결과는 `output/playwright/persona-audit/`, 대시보드 추가 검증은 `output/playwright/persona-dashboard/`에 보관한다. 실제 개인 거래를 외부 서비스에 전송하지 않았다. 화면 캡처만으로 완전한 접근성 적합성을 주장하지 않는다.

검증 결과: 전체 테스트 507개, 추가 QA 7개, 배포 빌드(공개 파일 186개) 통과. 예시 데이터 기반 브라우저 검증은 대시보드 5개·과거 입력 10개·달력 12개 흐름을 확인했다. 로컬 수정본이며 메인 사이트 배포는 별도이다.


## v197 사용자 피드백 반영

사용자는 소비 달력의 기존 디자인 유지와 대시보드·과거 거래 입력의 배치 개선을 선택했다. 변경 전에도 이미 3안이 적용되어 있었고, v196의 대시보드·과거 거래 검토 화면은 변화가 작았다는 피드백을 반영했다.

- 소비 달력: v195(c6ba5d4)의 HTML·CSS·렌더링으로 복원했다. 8개 지표와 월 메모 배치를 유지하며 보험·신용대출·할부금 계산은 그대로다.
- 대시보드: 소비지출·수입·기록 기준 남은 돈을 한 요약 영역에 가로로 배치했다. 전월 비교 그래프는 아래로 옮기고 분류별 소비와 카드 결제를 구분했다.
- 과거 거래 입력: 붙여넣기와 안내를 나누고, 검토 목록과 선택 거래 편집을 별도 영역으로 구성했다. 선택 행과 편집 제목을 연결하고 저장할 건수·내 소비 합계를 강조했다. PC 편집 필드는 두 열로 배치하며 모바일에서는 세로로 읽는다.

계산 모델·저장 처리·분류·중복 처리와 기존 화면 연결은 보존했다. 새 애니메이션이나 라이브러리는 추가하지 않았다. 비교 이미지는 같은 예시 데이터, 동일 1652px 브라우저 폭에서 실제 본문 영역을 캡처해 제목 위치와 축척을 맞춘다.

검증: 전체 테스트 507개, 추가 QA 7개, 공개 파일 186개 빌드 통과. PC·노트북·모바일에서 대시보드 화면 연결, 과거 거래의 수정·정산·할부·중복·저장 및 재접속, 달력 날짜 선택·출금 상세·메모 저장을 격리 브라우저로 확인했다. 로컬 미리보기이며 메인 사이트에는 배포하지 않았다.

## v198 거래 수정과 작성 예시

사용자가 추천 시안 중 거래 수정과 입력 예시를 선택했다. 소비 달력과 대시보드는 v197 그대로 유지한다.

- 선택 거래 이름을 수정 화면 제목으로 표시하고 날짜와 목록 순서를 함께 보여준다.
- 총 결제액·돌려받은 돈·내 소비 계산을 같은 영역에 배치하고, 잘못된 금액 입력 중에는 이전 계산식을 표시하지 않는다.
- 빈 실제 입력란 위에 날짜·내용·금액 예시 표를 둔다. 예시는 자동으로 입력되거나 저장되지 않는다.
- 입력 내용 확인 뒤 금액과 분류를 고칠 수 있고, 저장 전까지 가계부에 반영되지 않는다는 안내를 제공한다.

검증: 전체 테스트 508개와 QA 7개, 공개 파일 186개 빌드 통과. 격리 브라우저의 PC·모바일 입력·수정·저장·새로고침 등 14개 검사와 비교 뷰어 7개 검사를 통과했다. 소비 달력·대시보드의 실제 전후 캡처는 바이트 단위로 같다. 자료는 output/playwright/history-v198/와 design-qa.md에 보관한다. 로컬 반영이며 메인 사이트에는 배포하지 않았다.
